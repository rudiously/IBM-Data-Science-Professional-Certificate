# Supabase Integration Guide for Nivant Trekkers

## What You'll Get:
✅ Real-time updates visible to everyone
✅ Data stored in cloud database (not browser)
✅ Free forever (up to 500MB database)
✅ No server management needed

---

## Step 1: Create Supabase Account (5 minutes)

1. **Go to Supabase**: https://supabase.com
2. **Click "Start your project"**
3. **Sign up** with GitHub or email
4. **Create a new project**:
   - Project name: `nivant-trekkers`
   - Database password: Create a strong password (save it!)
   - Region: Choose closest to India (Singapore or Mumbai)
5. **Wait 2 minutes** for project to be created

---

## Step 2: Create Database Table (3 minutes)

1. **Go to "Table Editor"** (left sidebar)
2. **Click "Create a new table"**
3. **Table name**: `trek_data`
4. **Add columns**:
   - Keep `id` (auto-generated)
   - Keep `created_at` (auto-generated)
   - Add column: `data` (type: `jsonb`)
   
5. **Click "Save"**

---

## Step 3: Get Your API Keys (2 minutes)

1. **Go to "Settings"** (gear icon in sidebar)
2. **Click "API"**
3. **Copy these two values**:
   - `Project URL` (looks like: https://xxxxx.supabase.co)
   - `anon public` key (long string)

**Save these somewhere safe!**
